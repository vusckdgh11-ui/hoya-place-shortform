# HOYA 네이버 사진 수집기

1. 이 폴더를 압축 해제한다.
2. 크롬 주소창에 `chrome://extensions`를 연다.
3. 우측 상단 **개발자 모드**를 켠다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택한다.
5. HOYA Shortform 페이지를 한 번 새로고침한 뒤, 편집 화면에서 **크롬으로 네이버 사진 자동 수집**을 누른다.

확장 프로그램은 업체명을 기준으로 네이버 플레이스와 블로그 탭을 크롬에서 잠시 열어 사진을 읽은 뒤 닫는다. 사진은 Vercel·GitHub에 저장하지 않고 브라우저에서만 영상 재료로 사용한다.
